# TIO語音精靈 — 使用說明

## 怎麼開始？

安裝完成後，桌面上會有一個叫 **「TIO語音精靈」** 的捷徑。

**滑鼠左鍵點兩下就好。** 不用打任何指令。

> 桌面上找不到？直接去解壓縮出來的資料夾裡點 `4_開始使用.bat`，一樣的。

會跳出一個黑色視窗，長這樣：

```
  TIO語音精靈
  ════════════════════════════════════════════

  1  會議即時字幕      － 開會當下就看到字幕
  2  影音檔轉逐字稿    － 已錄好的錄音、錄影轉成文字
  3  即時雙語字幕      － 同時出原文＋譯文（可翻中英日文）
  4  逐字稿轉雙語對照  － 整份翻，品質比即時翻好很多
  5  逐字稿重新排版    － 從 .json 重做／改講者名字，不花錢
  6  即時語音翻譯      － 只聽口譯，不聽原音（口譯模式）
  9  API 金鑰設定      － 換金鑰、檢查是否有效、清除記住的
  0  關閉

請輸入號碼後按 Enter：
```

**你只要打一個數字，然後按 Enter。** 後面它會一步一步問你，照著回答就好。

---

## 第一次用，先試工具「2」（不用自己的錄音檔也能試）

按 `2` → 開啟的選檔案視窗裡，找到這個資料夾底下的 `data\meeting_16k_mono.wav`
（是內建的示範錄音，兩個人講中文，47 秒）→ 開啟 → 一路 Enter 到底。

這樣可以在還沒有自己的錄音檔之前，先看看成品長什麼樣子。跑完會問你要不要打開來看，
按 `1` 就會自動開啟。

## 1️⃣ 會議即時字幕

**用在什麼時候：** 開會的當下，想邊開邊看到字幕。

**怎麼做：**

1. 點兩下桌面圖示 → 按 `1` → Enter
2. 它問你要錄哪種聲音：
   - 按 `1` = **線上會議**（Teams / Google Meet / Zoom）
     → 錄的是「電腦喇叭放出來的聲音」，所以對方講什麼都收得到
     → 🔴 精確地說，錄的是 **Windows 預設的播放裝置**。會議軟體的喇叭要選同一顆：新版 Teams（2026-09-19
       一台筆電實測）沒有「系統預設」可選，要到 Teams 的裝置設定手動選 Windows 目前預設的那一顆，選到別顆會整場錄不到對方的聲音
       （開始時畫面上的「聲音來源：…」就是正在錄的那一顆）
   - 按 `2` = **實體會議**（大家在同一間會議室）
     → 錄的是麥克風。電腦有**兩支以上**麥克風時會問「用哪一支」（只有一支就不問）：
       選 `1`（直接 Enter）＝**自動**跟著 Windows 預設，中途拔插耳麥會跟著換；
       選其他號碼＝**固定用那一支**，拔掉就等它插回來。
       多人會議**不要用耳麥**（它是貼著嘴巴設計的）：有會議用的外接麥克風就固定用它，沒有就用**筆電內建的麥克風陣列**，
       選好之後用畫面上的「收音檢查」確認真的收得到。
       接著會問「現場有沒有擴音器放出來的聲音要收」：一般按 `1`；
       要收擴音器的聲音才按 `2`（完整收音，不保證收得到，見下方「混合會議怎麼架」）
   - 按 `3` = 兩個都要（你人在線上會議，也想收到自己講的話）
     → 麥克風一樣會問「用哪一支」。選了**固定用那一支**時，拔掉耳麥只會停掉**麥克風**那一路；
       電腦播的聲音照樣會出字幕（耳麥拔掉後聲音改從筆電喇叭播，程式會跟著改錄喇叭那一顆；拔插的那一下，電腦聲音也可能斷約 1 秒，會自動接回）
3. 它問你**專有名詞** → 打「深耕計畫 研發處 會計室」這種，中間空一格
   （這步很重要，會讓正確率差很多。不想打就直接按 Enter 跳過）
4. 它問你這場會議叫什麼名字 → 隨便打，或直接 Enter
5. 按 Enter 開始

**開始之後你會看到：**
- **灰色的字** = 還在辨識中，會一直跳動修正 → 這是正常的，不用管它
- **白色的字** = 已經鎖定的句子。**一句話講完就鎖一句**，不用等你停下來

**會議結束怎麼停？**
在那個黑色視窗裡按 **Ctrl + C**（Ctrl 鍵壓著不放，再按 C）。

**檔案會存到桌面**，一次兩個：
- `.md` — 給人看的，可以直接複製到 Word
- `.txt` — **備份用**。萬一電腦當機或程式被關掉，字幕都還在這個檔裡

> ⚠️ 即時字幕**分不出誰在講話**（這是 Google 目前的限制）。
> 需要標出「處長說」「秘書說」的話，請用下面的工具 2。

## 2️⃣ 影音檔轉逐字稿 ⭐ 最常用

**用在什麼時候：** 會議已經錄好了（手機錄音、Teams 錄影、隨身錄音筆都可以），
想變成有講者、有時間的文字稿。

**怎麼做：**

1. 點兩下桌面圖示 → 按 `2` → Enter
2. **會跳出選檔案的視窗** → 找到你的錄音或錄影檔，點「開啟」
   （mp3、m4a、wav，或 mp4、webm（瀏覽器錄的影片）這類錄影檔都可以，它會自己處理）
3. 它問你**專有名詞** → 打「深耕計畫 研發處 會計室 教學組長」
4. 它問你**講者名字** → 照「誰先開口」的順序打，例如「處長 秘書」（名字本身有空白，例如英文全名，就改用逗號隔開：「Chair Wang, Ms Li」）
   （不知道就直接 Enter，會變成「講者1」「講者2」；超過 28 分鐘會切段，名字只套在第 1 段，見下方）
5. 等它跑完

**要等多久？** 一小時的錄音大約 1～3 分鐘。

**跑完會問你要不要打開來看**，按 `1` 就會自動開啟。檔案在桌面，長這樣：

```
**[00:00:00] 處長**

好，那我們今天的研發處會議就開始了。第一個案子是深耕計畫的期中報告。

**[00:00:09] 秘書**

我這邊補充一下，就是那個經費核銷的期限已經延到10月31號了。
```

> ℹ️ 有時候某一句的標題後面會多一個 **〔補轉〕**（用內附的示範檔跑，秘書這句就可能會有）：
> 那句是整理正文時漏掉、程式從原音把那一小段剪出來單獨再轉一次補回來的，檔頭也會多一行寫有幾處。
> 講者和時間取自第一次辨識，建議對照錄音核對一下。補不回來的，檔頭會寫「可能不完整」並列出時段。

> ℹ️ **會議裡有人講英文**（例如外賓致詞）：英文會照原文留在逐字稿裡。但分講者那一趟常聽不到中文會議裡的英文，
> 所以**那一段的講者和時間可能不準**（常被併到前一位講者的段落裡），檔頭會寫
> 「這 N 秒的錄音裡有聲音，逐字稿卻沒有標到這段時間」，請對照錄音聽一下那段。
> （2026-09-25 自製會議實測：舊版在這種情況會把整段英文安靜地漏掉，檔頭什麼都沒寫。）

> 💡 **專有名詞真的有用。** 實測不填的話，它會把「會計室」聽成「會計師」、
> 「深耕計畫」寫成「深耕計劃」。填了就會自動修正。
> 建議固定填：`深耕計畫 研發處 教務處 會計室 教學組長 核銷 期中報告`

### 超過 28 分鐘的錄音會自動切成好幾段

Google 官方文件寫明：開「分講者＋時間軸」時，**模型每次只處理 30 分鐘的音訊**。
所以程式把長錄音切成每段 28 分鐘以內，留一點安全邊際。

> ⚠️ 不過**切短不代表就不會出錯**。實測長錄音會遇到兩種狀況：某一段的**中間整片沒辨識到**
> （28 分鐘的段落遇過），或**正文被同一批話反覆灌滿**（45 分鐘和 28 分鐘的段落都遇過）——
> 所以真正的把關是下面那些檢查，不是分段長度。

你會看到兩件事：

- 畫面上會說「單段上限 28 分鐘，這份錄音切成 N 段」
- 每段各自判斷講者，跨段認不出是不是同一個人：第 2 段起的講者寫成「**第2段講者1**」這種樣子；
  你轉檔前填的講者名字**只套在第 1 段**（以前會照編號套到每一段，第 2 段就可能張冠李戴）。
  要統一名字，用工具 5 看著每位講者的第一句重新命名（同一個人在不同段可以填同一個名字）

> 🔴 **如果某一段漏了內容或出現異常，檔頭與畫面會標出來**（寫明第幾段、問題是什麼、
> 建議你把哪一段剪出來單獨再轉一次）。程式會檢查六件事：某一段的中間有沒有整片沒辨識到、
> 兩趟辨識的產出量有沒有嚴重對不起來、正文有沒有大量重複、第一次辨識有聽到的話在整理後的正文裡
> 是不是不見了（不見的會先剪出來單獨補轉，標〔補轉〕；補不回來才列出來），
> **錄音裡有聲音、逐字稿卻沒有標到的時段**（連續有聲音超過 10 秒、或沒標到的時間裡 30 秒內聲音加起來有 6 秒以上才報；音樂、掌聲也會被列出來，聽一下就知道），
> 以及**段落的時間有沒有互相重疊或倒退**（同一段時間被放了兩套內容時，那一帶的講者與時間可能對不上）。
>
> ⚠️ 但**沒有標不等於一定沒問題**。已知檢查不到的情況：很短的小缺口（連續不到 10 秒、30 秒內加起來也不到 6 秒）、
> 聲音很小（接近背景雜音）的講話、整段被一個很長、字數又正常的段落蓋住（超過 1 分鐘卻幾乎沒字的段落，會照樣檢查它的中間）、
> 錄音從頭到尾都很吵、講話沒比背景大多少（例如一直有背景音樂或轉播聲；程式判斷這項檢查看不準時，檔頭會另外寫一行
> ℹ️「這份錄音幾乎沒有安靜的時候…」，那一行只是說明、不算缺口）。重要的會議還是要抽查。

> ⚠️ **2026-09-16 之前產出的長逐字稿，建議重轉一次。** 舊版沒有上面說的那些檢查，
> 出問題的時候完全不會講。實測一份 2 小時 57 分的會議：有一段的中間 14 分鐘完全沒辨識到，
> 另一段的正文有九成是同一批話反覆出現（同樣 13 句循環了 6 次）——兩種都沒有任何警告。
> 重轉的方式跟第一次一樣：按 `2` → 選同一個錄音檔，然後**看檔頭有沒有警語**。

## 3️⃣ 即時雙語字幕 ⭐ 看外語演講、或替中文演講配外語字幕用

**用在什麼時候：** 看英文的線上研討會、國外大學的說明會、YouTube 英文影片，
想要**同時看到英文原文和中文翻譯**。聽中文演講、要配英文或日文字幕，也是用這一個。

**怎麼做：**

1. 點兩下桌面圖示 → 按 `3` → Enter
2. 它問聲音從哪來：
   - 按 `1` = **電腦播出來的聲音**（YouTube、線上研討會）
   - 按 `2` = 麥克風（現場有外賓演講）→ 會多問「現場有沒有擴音器的聲音要收」，一般按 `1`
   - 按 `3` = **兩者都要**（實體＋線上的混合會議）
     → 麥克風會問「用哪一支」（同功能 1）。選了**固定用那一支**時，拔掉耳麥只會停掉**麥克風**那一路；
       電腦播的聲音照樣會出字幕（拔插的那一下可能斷約 1 秒，會自動接回）
   - 按 `4` = **已經存好的影音檔** ← 選檔案，不會錄到別的聲音
3. **它問「要快，還是要準？」**
   - 按 `1` **準**（建議）：等整句講完才翻，延遲約 2～3 秒，譯文語序正常
   - 按 `2` **快**：邊聽邊翻，延遲約 1 秒，但語序偶爾會卡住
4. 它問要翻成什麼語言 → 按 `1` 繁體中文、`2` 日文、`3` 英文
   （講者說什麼語言不用先設定，程式會自己聽出來；2026-10-07 實測法文、西班牙文、日文的演講翻成英文，結果跟指定講者語言時一樣）
5. 按 Enter 開始

**畫面會長這樣：**

```
[00:02] Thank you for joining today's session on research assessment.
        謝謝大家參加今天的研究評估會議。

[00:22] First, a seed funding scheme for cross-disciplinary projects.
        第一，建立一個種子基金計畫，用於跨學科專案。
```

灰色是原文，藍色是譯文，**同時出現**；
延遲看你上一步選哪個模式——選「準」約 2～3 秒，選「快」約 1 秒。

> ⚠️ **用「電腦播出來的聲音」時，它會錄到 Windows 預設播放裝置當下播的所有聲音。**
> 開始前請先把不相干的影片、音樂關掉，不然會混在一起。
> 線上會議時，會議軟體的喇叭也要選這一顆（新版 Teams 要手動選，見功能 1 的說明；
> 開始時畫面上的「聲音來源：…」就是正在錄的那一顆）。
> 想避免這個問題，就用選項 `4`（直接讀影音檔）。

**「快」跟「準」差在哪？** 同一句英文的實際輸出：

| | 快（邊聽邊翻） | 準（整句才翻） |
|---|---|---|
| | 我們大學已經增加了國際合作率 **15%今年**。 | 本校的國際合作率**今年**提升了 15%。 |
| 延遲 | 約 1 秒 | 約 2～3 秒 |

> 💡 「快」模式的語序問題不是顯示太早造成的，是模型邊聽邊翻、還沒聽到後半句就先翻了。
> 「準」模式是等整句講完才送去翻，所以語序正常。
> 要**最高品質**（可以慢慢等）的話，用工具 4。

> 🔴 **用麥克風收講者說的中文、要翻成英文時，請選「準」。** 2026-09-19 筆電實測，這種情況「快」模式
> 很不穩定：同一段話有時整段沒有字幕：實測講的內容 0%～19% 出現在字幕上，「準」模式用同一支麥克風是 78%～97%（實測次數少，僅供參考）。
> 讀內建範例檔、錄電腦播出來的新聞則正常；但把麥克風錄下的講話存成檔再讀，一樣不穩定。工具 6 用的就是「快」模式，所以也一樣。

> ⏱️ 「快」模式的原文行要等到句號、問號這類句尾標點、停頓 2.5 秒或累積滿 90 字才會出現。
> 講中文時，轉錄出來的句子多半用逗號，連續講話時原文可能晚 20 秒以上才出現——這是顯示方式造成的，不是模型慢。

## 🏢 混合會議（實體＋線上）怎麼架

> 🔴 **2026-09-22 實測後改寫。** 舊版建議「先用麥克風收會議室喇叭」，實測站不住腳：
> - **喇叭放出來的聲音，麥克風幾乎收不到**：Windows 的收音處理會把它當雜音刪掉。
>   筆電喇叭播一段會議錄音，辨識出 **0 句**；手機喇叭放在 2 公尺外，也是 **0 句**。
> - 同一顆筆電內建麥克風收**真人**講話，站 3 公尺都辨識正常。
>
> 結論：**線上與會者的聲音要從電腦裡直接拿**，不要讓它先從喇叭放出來、再用麥克風收回來。
> 把喇叭音量調大也沒用——聲音是在麥克風那一端被刪掉的。

### 做法 1（建議）：字幕電腦也加入線上會議，選「兩者都要」

- 字幕電腦用瀏覽器或會議軟體**加入同一場會議**（在會議軟體裡把自己的麥克風**靜音**，免得現場聲音再送一次到線上）
- TIO 選 **`3` 兩者都要**：線上與會者的聲音直接從電腦裡拿（數位的，不經過空氣），現場講者用麥克風收
- 要投影字幕：把這台電腦的畫面延伸到投影機
- 萬一出現「同一句話出現兩次」，就是喇叭的聲音又被麥克風收了一次——戴耳機或把喇叭關小

### 做法 2（最穩，但要有設備）：從會議室音響直接拉線

- 會議室混音器／會議主機的**錄音輸出**（REC OUT、AUX、PROGRAM OUT）→ **USB 錄音介面** → 在 Windows 設成預設麥克風 → TIO 選 **`2` 麥克風**
- ⚠ 要取「迴音消除之前」那一路；**不要**插筆電的耳麥孔（線路訊號太大會破音）。不確定就請會議室的設備人員幫忙

### 做法 3（備案，不保證）：只能用麥克風收擴音器

- 選 **`2` 麥克風**，它問「現場有沒有擴音器放出來的聲音要收」時選 **`2`（完整收音）**：不經 Windows 降噪
- 實測：筆電喇叭播會議錄音，一般收音 0 句 → 完整收音 4 句（原檔 7 句）；**手機小喇叭放 2 公尺，兩種都 0 句**
- 所以只能當備案，正式會議前一定要在現場試跑

### 現場講者用哪支麥克風

- **耳麥放在桌上收遠處的人不可靠**：實測真人站 3 公尺，筆電內建麥克風兩次都辨識正確；耳麥放在桌上，兩次裡有一次整句辨識錯
  - 🔴 這組實測只比了**兩支**：筆電內建麥克風陣列、放在桌上的 3.5mm 耳麥。**沒有測過會議用的外接／USB 麥克風**，
    所以**不能**推論成「內建的比外接會議麥克風好」——那類本來就是為「放在桌上收整桌」做的，有接就優先用它
  - 不確定哪支好：開始後看畫面上的「收音檢查」，有人講話時顯示「有收到聲音」就對了；「聲音偏小」就換另一支試
- 耳麥請**戴在頭上**給一個人用，不要放桌上當會議麥克風

### 🔴 開始後不要拔插耳麥

- 耳麥插頭鬆了或拔掉，程式會**自動接回**，畫面會出現「⚠ 麥克風中斷了…」→「✓ 麥克風接回來了」；但中斷的那幾秒不會有字幕
- **電腦播的聲音**（線上會議、影片）也會自動接回：拔插耳麥時就算喇叭沒被拔，錄電腦聲音的那一路也可能斷一下，
  畫面出現「⚠ 抓不到電腦播出的聲音了…」，電腦聲音約 1 秒就接回，穩定之後畫面說「✓ 電腦聲音接回來了」（通常再過約 1 秒）；功能 1、3 遇到 Windows 預設的播放裝置跟著換了，會說「✓ 電腦聲音改從這顆錄：…」。
  V1.38 以前，這種喇叭沒被拔、錄音卻斷掉的情況不會自己接回，要按 Ctrl + C 重開
- 功能 6 的**口譯語音**也會自動接回：畫面出現「⚠ 口譯語音斷了…」→「✓ 口譯語音接回來了」。口譯從喇叭出來時會斷一下、最多約 2～3 秒
  （就算喇叭沒被拔，拔插耳麥也會讓它斷一下）；從耳機出來時，要等耳機插回去，插回後約 1 秒恢復
- 要換耳麥或喇叭，最保險是先按 Ctrl + C 結束、再重開一次（字幕會存成兩個檔）

### 畫面上的「🎚 收音」那幾行

開始後約 6 秒會出現一次，告訴你**聲音有沒有進到程式裡、以及會不會有字幕**：

```
  🎚 收音檢查（聲音有沒有進到程式裡）
     麥克風　：▮▮▮▮▮▯▯▯  有收到聲音（-45 dB，字幕出得來）
     電腦聲音：▯▯▯▯▯▯▯▯  電腦現在幾乎沒有在播（-95 dB，沒有聲音就不會有字幕）
```

| 看到這個 | 意思 | 要做什麼 |
|---|---|---|
| **有收到聲音** | 音量夠，辨識得出來 | 不用做什麼 |
| **聲音偏小** | 字幕可能漏字、辨識不準 | 麥克風：移近講者，或改用別支麥克風；電腦聲音：把播放音量調大（見下方） |
| **幾乎沒有聲音** | 不會有字幕 | 檢查麥克風、耳麥插頭有沒有鬆 |
| **電腦現在幾乎沒有在播** | 電腦沒在放聲音（線上會議沒開、或聲音走到別的喇叭） | 確認線上會議的聲音是從這台電腦播出來 |
| **沒有收到資料** | 裝置可能被拔掉了 | 插回去，程式會自動接回 |

- 長條越多格＝聲音越大；括號裡的 dB 是給技術人員看的，截圖回報時用得到
- 之後**只有超過 30 秒沒有新字幕**時才會再出現（一直沒字幕就每 2 分鐘一次，不會洗版），並多一句判斷：
  有一路是「有收到聲音」→ 問題比較可能在網路或辨識；都只到「聲音偏小」→ 先把音量調大或把麥克風移近；聲音沒進來 → 先查收音
  （「兩者都要」時一路有收到、另一路偏小或沒聲音 → 會點名那一路，分兩種情況講：講話的人在那一路，就先處理那一路的收音
  （麥克風移近、看有沒有被靜音，或把播放音量調大）；講話的人在另一路，問題比較可能在網路或辨識）
  （「快」模式聲音夠大卻一直沒字時，會再建議改用「準」模式：有些語言或內容，「快」模式只出翻譯語音、不出字）
- **電腦聲音連續 20 秒都偏小**時，會主動跳一次黃色的「⚠ 電腦播出的聲音一直偏小」，並寫出是哪一顆播放裝置
  （字幕還斷斷續續在出的時候也會提醒）：把那一顆的音量調大（工作列右下角的喇叭圖示），或把會議軟體／影片播放器
  自己的音量調大。TIO 錄到的是**調過音量之後**的聲音，播放音量太小，字幕就會漏字
- 字幕檔的檔頭也會記下這一場用的是哪種收音、哪支麥克風，事後查問題用得到

### 🔴 正式會議前一定要先試跑

**收音位置這種事紙上談兵不準，一定要現場實測。** 建議：

1. 在**真正要用的那間會議室**，用**真正要用的那台電腦和麥克風**
2. 找一兩個同事，一個在現場講話、一個從線上講話
3. 開著字幕跑 **10 分鐘**就好

要確認這四件事：

| 檢查 | 不通過的話怎麼辦 |
|---|---|
| 現場講者的話有沒有被辨識到 | 麥克風往講者方向移，或改用 USB 會議麥克風；不要用放在桌上的耳麥 |
| **線上與會者的話有沒有被辨識到** | 改用做法 1（字幕電腦也加入會議、選「兩者都要」）。**調大喇叭音量沒有用** |
| 有沒有同一句出現兩次 | 這是回音，字幕電腦改戴耳機或把喇叭關小 |
| 字幕的字夠不夠大 | 在字幕視窗按 Ctrl ＋「+」放大（可連按），Ctrl ＋「-」縮小。坐多遠就要多大：字高（公釐）大約要「最遠距離（公尺）× 9」 |

> 💡 順便把常用的**專有名詞**先想好（單位名、計畫名、常出席者的職稱），
> 正式會議時直接填進去，正確率差很多。

## 4️⃣ 逐字稿轉雙語對照 ⭐ 要給外賓看的文件用這個

**用在什麼時候：**
- 中文會議紀錄要給國際合作對象看 → 翻成英文
- 國外研討會的錄影 → 翻成中文
- 要做中英對照的正式文件

**跟工具 3（即時雙語字幕）差在哪？**

| | 工具 3 即時字幕 | 工具 4 這一支 |
|---|---|---|
| 什麼時候用 | 邊聽邊看 | 事後整理文件 |
| 翻譯方式 | 邊聽邊翻，像現場口譯 | 整份一起翻，看得到前後文 |
| 品質 | 語序偶爾怪 | **好很多** |
| 速度 | 即時 | 要等一下 |

**怎麼做：**

1. 點兩下桌面圖示 → 按 `4` → Enter
2. **選檔案** — 錄音檔、影片檔、逐字稿 `.json`、字幕 `.srt` 都可以
3. 選要翻成什麼（自動判斷／中文／英文／日文）
4. **固定譯名**（選填但強烈建議）：寫成 `深耕計畫=Higher Education Sprout Project`（翻成日文時寫 `深耕計畫=高等教育深耕計画`），
   多組用分號 `;` 隔開（譯名裡有空白沒關係）。
   這樣專有名詞全篇統一，不會一下這樣翻一下那樣翻
5. 這份文件的背景（選填）：例如「研發處深耕計畫會議」，模型會翻得更貼切
6. **專有名詞**（選填，只有選錄音或錄影檔時會問）：單位名、計畫名、人名先餵進去，正確率差很多
7. **講者名字**（選填）：填了之後，產出的文件講者欄會寫「處長」「秘書」，
   而不是「講者1」「講者2」（翻成英文時沒填的講者會寫 Speaker 1、日文寫 話者1）。
   選 `.json` 時它會先把每位講者的第一句印出來讓你對號入座；
   那份逐字稿在工具 2 **已經填過名字**的話，直接 Enter 就沿用那些名字，不用再填一次。
   選錄音或錄影檔時還沒轉檔、不知道有幾位，可以照「先開口的順序」填，不確定就直接 Enter
8. 等它跑完

**會產生四種檔案**（桌面上，同一個檔名開頭）：

| 檔案 | 用途 |
|---|---|
| `_對照.md` | 一段原文、一段譯文，給人讀的 |
| `_對照表.md` | 表格（時間／講者／原文／譯文），**方便貼進 Word 或 Excel** |
| `_en.md`（或 `_zh-TW.md`、`_ja.md`） | 只有譯文的乾淨版 |
| `_對照.json` | 機器格式，之後要重新排版或再翻別的語言時用得到 |

**實際產出長這樣：**

```
**[00:00:00] 處長**

> 好，那我們今天的研發處會議就開始了。第一個案子是深耕計畫的期中報告。

Alright, let's start today's Office of Research and Development meeting.
The first item is the midterm report for the Higher Education Sprout Project.
```

（「Office of Research and Development」和「Higher Education Sprout Project」
是靠「固定譯名」指定的；不指定的話模型會自己隨便翻。）

## 5️⃣ 逐字稿重新排版 ⭐ 出事的時候救命用

工具 2 每次轉完，除了給人讀的 `.md`，旁邊都會多留一個同名的 `.json`。
那個 `.json` 存的是原始資料（每一段的時間、講者、文字）。這一支就是把它重新排成 `.md`。

**純本機處理，不連網、不呼叫 API、完全不花錢，幾秒就好。**

**用在什麼時候：**

| 情況 | 沒有這支的話 | 有這支 |
|---|---|---|
| 轉三小時的錄音，轉到一半電腦當機／不小心關掉視窗 | 整份重轉，再花一次錢和時間 | 選旁邊的 `.partial.json`，把已經轉好的部分救回來 |
| 講者名字填錯了（把「處長」跟「秘書」填反） | 整份重轉 | 重填一次，10 秒解決 |
| `.md` 被誤刪、被覆蓋 | 整份重轉 | 直接重做 |

**怎麼做：**

1. 點兩下桌面圖示 → 按 `5` → Enter
2. **選檔案** — 選工具 2 產生的 `.json`（或中斷時留下的 `.partial.json`）
3. 它會先告訴你「這份有幾段、幾位講者」，還會印出**每位講者的第一句話**，
   讓你對得出來誰是誰
4. 填講者名字（可以直接 Enter 跳過：工具 2 當初填過名字的，就沿用那些名字；沒填過的用「講者1、講者2」）
5. 幾秒後 `.md` 就出現在桌面

> ⚠️ 超過 28 分鐘的錄音，工具 2 當初是**切成好幾段**分別辨識的。
> （Google 官方文件寫明，「分講者＋時間軸」這個模式每次只處理 30 分鐘的音訊，
> 所以程式留了安全邊際切在 28 分。）
> 每一段的講者是各自判斷的，第 2 段起的講者會列成「第2段講者1」這種樣子（跟第 1 段分開）。
> 第 3 步印出來的第一句話可以幫你認人：同一個人在不同段，就填同一個名字。
> （2026-09-25 之前轉的長逐字稿，不同段之間的「講者1」不保證是同一個人，這裡分不出來。）

## 6️⃣ 即時語音翻譯 ⭐ 像口譯耳機一樣，只用耳朵聽翻譯

**什麼時候用**：外賓來演講、跨國線上會議、看沒有字幕的外語影片，
你想要**用耳朵聽中文**，而不是一直盯著字幕看。

畫面上照樣會跑雙語字幕，結束一樣存檔——語音是多出來的，不是取代字幕。

### 🔴 錄「電腦播出來的聲音」時要指定兩條路線

這個模式最容易搞混的就是這件事，先講為什麼：

錄「電腦播出來的聲音」是側錄**系統預設播放裝置正在播什麼**。
所以「我不想聽到原音」**沒辦法靠靜音達成**——把它靜音，等於把錄音來源一起關掉。
唯一的做法是讓兩種聲音走兩條不同的路線：

| | 走哪裡 | 你聽得到嗎 |
|---|---|---|
| **① 原音**（會議的聲音） | 沒接線的數位輸出／HDMI、插著但你不會戴上的耳機、虛擬音效線 | **聽不到**（程式只拿它側錄） |
| **② 口譯語音** | 喇叭，或你戴著的耳機 | **聽得到** |

這樣開會時你**只會聽到翻譯**，不會兩種聲音疊在一起；口譯語音也不會被錄回去、
變成模型翻自己剛剛講的話（那會越滾越亂，而且每一圈都在花錢）。

程式會自動把 Windows 的聲音輸出切到①，**結束後自動切回來**。
萬一中途當機或被強制關掉，下次啟動時會自動補切回去，Windows 這一邊不會讓你留在「沒聲音」的狀態
（「預設通訊裝置」另外設過的話也會各自改回；會議軟體的喇叭要自己改回，見下方）。

> 🔴 哪一條「聽不到」**只有你知道**——光纖孔有沒有插線、耳機有沒有戴在頭上，
> Windows 查不到，程式不會猜。所以兩條都由你指定，選完會各播一聲讓你當場確認；
> 選反了可以馬上重選。

| 聲音來源 | 規則 |
|---|---|
| 電腦播出來的聲音 | 要指定兩條路線（見上表），選完會試聽驗證 |
| 麥克風 | 請戴耳機，並在選單上指定口譯從那副耳機出來（選完會試播一聲；電腦上可用的播放裝置剩一個時不會問）。選了喇叭的話，口譯會被麥克風錄回去，模型會一直重複翻同一句、停不下來，這段時間也一直在計費，程式擋不住 |
| 已存好的影音檔 | 沒有這個問題。檔案是直接讀的，原音根本不會播出來，本來就只聽得到翻譯；一樣會問口譯要從哪裡播（播放裝置剩一個時不問） |

### 怎麼用

1. 選單按 `6`
2. 選聲音來源
3. 選「電腦播出來的聲音」的話，依序指定兩條路線：
   **① 原音走哪一條**（你聽不到的那條）→ **② 口譯語音從哪裡聽**（你聽得到的那條）
4. 試聽：程式各播一聲。第一聲你應該**聽不到**、第二聲應該**聽得到**；
   不對就選「不對，兩條重新選」
5. 選「麥克風」或「影音檔」的話，改問**口譯語音從哪裡聽**：選你戴著的耳機（清單會標出目前的預設），
   選完試播一聲確認；沒聽到就選「沒有，重新選」。
   （電腦上可用的播放裝置剩一個時不會問，口譯直接從那一顆出來）
6. 選要翻成什麼語言（講者說什麼語言不用先設定，程式會自己聽出來）
7. 按 Enter 開始

> **會議軟體要另外設**：Teams／Zoom／Webex 有自己的喇叭設定，不一定跟著 Windows 走。
> **用新版 Teams 時，開始前一律先進 Teams 的裝置設定，把喇叭指定成①那一顆**——它的喇叭清單沒有
> 「系統預設」可選，不會跟著程式切換（2026-09-19 實測）；沒指定的話，原音不會進①，側錄不到就沒有翻譯。
> Zoom／Webex：切好了還是聽得到原音的話，進那個軟體的音訊設定，**直接把喇叭指定成①那一顆**。
> Chrome（Google Meet／YouTube）會跟著系統走，不用管。
> 🔴 **用完（或中途停掉）要記得改回來**：程式會把 Windows 的設定改回原本的喇叭，但改不到會議軟體。
> Teams／Zoom／Webex 的喇叭如果照上面指定成①，要自己改回你平常聽的那一顆，不然下一場會議會聽不到聲音。

> **① 那一顆的音量不要拉到 0**：有些電腦側錄到的音量會跟著它變小。
> 實測調到 8% 仍然翻譯正常，所以不必調大，這一句是保險起見的建議。

> **只有一個聲音輸出怎麼辦**：接上耳機通常會多一條路線（耳機當①、喇叭當②，耳機不要戴上；2026-09-19 一台筆電的
> 有線耳機實測可以，藍牙還沒測；有些電腦的喇叭和耳機是同一條，接了也不會多）；
> 或裝一條虛擬音效線（例如免費的 VB-CABLE），它就是一條永遠聽不到的路線，專門拿來放原音。

### 會遇到的狀況

- **聲音比畫面慢一點**：正常，同步口譯本來就會落後講者約 1～2 秒
- **講者講太快時會跳過幾句語音**：程式寧可跳，也不要讓你的耳朵越落後越多；
  **字幕是完整的**，結束後看存檔就好，畫面最後會告訴你跳了幾秒
- **聲音忽男忽女**：這是模型本身的限制（Google 官方文件也寫了），長停頓後音色可能變
- **每 8 分鐘會換一次連線**：字幕不受影響，語音可能斷半句
- **講者對著麥克風說話、要翻成英文時很不穩定**：有時整段翻不出來（見工具 3「快」模式的說明）。
  這種情況改用工具 3 選「準」看字幕比較可靠

### 只有「快速模式」有語音

工具 3 的「準確模式」是用文字模型翻的，沒有語音可以播。
工具 6 固定走快速模式（也就是 Google 的同步口譯模型）。

## 💳 免費 vs 付費：先查清楚再錄真實會議

> ⚠️ **這件事很重要，跟你的錢包和資料安全都有關，不要跳過。**

你剛申請的 API 金鑰，**預設是免費層**。免費層跟付費層差在：

| | 免費層 | 付費層（Tier 1 以上） |
|---|---|---|
| 費用 | 不收費 | 用多少算多少，一小時會議約 20 塊台幣 |
| **你的錄音會不會被拿去訓練** | **會** | 不會 |
| **真人審閱者可能讀到** | **可能** | 不會 |

**怎麼查自己是哪一層：**
1. 去 `aistudio.google.com` → 左側 **Get API key**
2. 找到你這把金鑰所屬的專案，旁邊會顯示 **Free** 或 **Paid**
3. 是 Free 的話，點 **Set up Billing** 綁一張信用卡就會變付費層

### 🔴 結論：要拿來錄真實會議，請開通付費層

不是「建議」，是**這個工具的使用前提**。三個理由：

**① 資料會被拿去訓練，人工審閱者可能讀到**（上面那張表）
校務會議談的是人事、經費、審查意見、學生個資，這一條就足以否決免費層。

**② 免費層的額度，Google 已經不公開了**
官方 rate-limits 頁面現在**沒有任何逐模型的額度表格**，只留一句話叫你自己去 AI Studio 看：

> "Rate limits depend on a variety of factors (such as your usage tier) and can be
> viewed in Google AI Studio."
> —— [ai.google.dev/gemini-api/docs/rate-limits](https://ai.google.dev/gemini-api/docs/rate-limits)（2026-09-08 查，頁面標示更新於 2026-09-02）

所以**沒有人能告訴你免費層一天能跑幾小時會議**——包括我。要知道自己的額度，只能登入
[aistudio.google.com/rate-limit](https://aistudio.google.com/rate-limit) 用你自己的帳號看。

同一頁還寫著：

> "Specified rate limits are not guaranteed and actual capacity may vary."
> （公告的額度不保證，實際容量可能不同）

會議開到一半才發現額度不夠，是沒辦法事先算出來避開的。

**③ 每日額度不是台灣時間午夜重置**

> "Requests per day (RPD) quotas reset at midnight Pacific time."

美西午夜 ≈ **台灣時間下午 3～4 點**（依美國日光節約時間而定）。早上開會把額度用完，
要等到當天下午才恢復；下午的長會議則可能開到一半額度突然重置或耗盡。

> ⚠️ 還有一條容易踩：**額度是算在「專案」上，不是算在「金鑰」上。**
> 同一個專案底下發好幾把金鑰分給同事，大家是共用同一份額度，會互相排擠。
> 每個人請用**自己的 Google 帳號**建立自己的專案。

**沒有查清楚、還是免費層的話：**
- ✅ 可以放心用：公開演講、對外說明會、自己的測試錄音
- ❌ **請先升級成付費層再用**：談人事、經費、審查意見、有個資的會議


## 出問題怎麼辦？

| 狀況 | 怎麼處理 |
|---|---|
| 點了之後有個視窗閃一下就不見，接著出現選單 | 正常。`4_開始使用.bat` 會另開一個「TIO」視窗放選單，自己的視窗隨即關掉 |
| 選單出錯了 | 程式會停下來顯示原因和技術細節；把整個視窗截圖，再點兩下 `6_診斷.bat` 一起截圖回報 |
| 選單沒出現，視窗裡是一段英文錯誤，停在「請按任意鍵繼續」 | 程式檔案不完整或壞掉了（例如解壓縮沒解完、被防毒軟體隔離）。重新解壓縮一次、再點 `3_安裝.bat`；還是一樣就把這個視窗截圖，連同 `6_診斷.bat` 的畫面一起回報 |
| 字幕都沒出現 | 檢查電腦有沒有在放聲音；線上會議記得選 `1` 不是 `2`。會議軟體的喇叭要選 **Windows 預設的播放裝置**（2026-09-19 一台筆電實測：新版 Teams 沒有「系統預設」可選，要在 Teams 的裝置設定手動選同一顆），開始時畫面上的「聲音來源：…」就是正在錄的那一顆。功能 6 選「電腦播出來的聲音」時例外：會議軟體的喇叭要選你在選單上指定的**①那一顆**（見功能 6 的說明），不是平常的 Windows 預設 |
| 選了麥克風，程式說「沒有可用的聲音來源」就結束、沒有檔案 | 這台電腦沒有接麥克風，或 Windows 的隱私設定擋住了（設定 → 隱私權與安全性 → 麥克風）。接上麥克風後再開一次 |
| 逐字稿的檔頭寫「可能不完整」 | 有六種原因：① 錄音後段沒有辨識到內容（靜音、音樂、雜音）② 同一段話大量重複時被整理掉了 ③ **某一段出狀況**（那一段的後面或中間整片沒辨識到、兩趟辨識的結果對不起來，或正文被同一批話反覆灌滿）④ 第一次辨識有聽到的某句話，整理後的正文裡沒有、單獨補轉也沒補回來（檔頭會寫時段和講者）⑤ **錄音裡有聲音、逐字稿卻沒有標到那段時間**（連續超過 10 秒、或 30 秒內加起來 6 秒以上；常見是中文會議裡的英文發言、音樂或掌聲，檔頭會寫時段；錄音從頭到尾都很吵、講話沒比背景大多少時，這項檢查看不準，檔頭會另外寫一行 ℹ️ 說明，那一行不算缺口）⑥ **段落的時間互相重疊或倒退**（常見於很長、夾雜多種語言的錄音；檔頭會寫時段，那一帶請對照錄音聽）。①②，以及某一段後面沒內容的情況，檔頭會寫辨識到第幾分鐘；其他情況，檔頭會寫是第幾段、哪個時段出問題。需要那一段的話，把它另外剪出來再轉一次（②③④ 的檔頭另外有寫建議怎麼剪） |
| 轉檔到一半關掉視窗 | 程式會先刪掉電腦裡的暫存錄音和雲端上的那份才結束。**超過 28 分鐘**的錄音會自動切成多段，已經整段轉完的部分留在 `.partial.json`，用工具 5 可以救回；**28 分鐘以內是一整段處理**，要等那一段的兩趟辨識、對齊、補轉全部做完才會存檔，**辨識中途**關掉就不會留下 `.partial.json`、只能整份重轉；但那一段全部跑完之後才出事（例如寫檔失敗）仍會留下，所以還是先看一眼桌面有沒有這個檔 |
| 轉檔或翻譯到一半網路斷了 | 網路整個斷掉時（例如 Wi-Fi 斷線），程式會自己等網路回來：每 20 秒再試一次，最多等 5 分鐘，網路一回來就接著做，畫面會顯示「網路回來了」；網路只是不穩、斷一下就好的，照舊重試幾次。等了 5 分鐘還沒回來：**轉檔**會停下來，超過 28 分鐘的錄音已經整段轉完的部分照樣做成逐字稿（檔頭列出缺哪幾段），28 分鐘以內的錄音（或第一段就斷）沒有產出，網路好了要整份重轉；例外是斷在「講者分段」那一步會改用估算、照樣做完，斷在「補轉」那一步會跳過、寫進檔頭。**翻譯**會停下來，已經翻好的照樣存檔，沒翻到的段落會標出來（等網路時按 Ctrl+C 結束也一樣；一段都還沒翻好時按 Ctrl+C 不會留下檔案）。翻譯的輸入是錄音檔時，轉逐字稿和翻譯兩個步驟各自最多等 5 分鐘 |
| 同一句話出現兩次 | 混合會議的回音：開會電腦的喇叭和麥克風互相收到了，改戴耳機 |
| 現場講者收得到、線上的人收不到 | 線上的人要從電腦裡直接拿：字幕電腦也加入會議、選「兩者都要」（見上方混合會議章節「做法 1」）。調大喇叭音量沒有用 |
| 字幕的字太小 | 在字幕視窗按 Ctrl ＋「+」放大（可連按），Ctrl ＋「-」縮小；開始時畫面上也有這行提示（Ctrl ＋ 0 是官方的「還原字級」鍵，但會跟自然輸入法衝突，所以不教） |
| 字幕突然停了（耳麥插頭鬆了、拔插過） | 程式會自動接回並顯示「✓ 麥克風接回來了」或「✓ 電腦聲音接回來了」（換錄別顆時是「✓ 電腦聲音改從這顆錄：…」）；如果一直沒出現，按 Ctrl + C 結束再重開（已經出來的字幕都有存） |
| 中文變成方塊或亂碼 | 改用「Windows Terminal」開啟（工作列搜尋「Terminal」），舊版的黑色命令提示字元對中文字型支援較差 |
| 字幕出現簡體字 | 大部分情況已經處理掉了，**剩下兩種**：① 功能 3 選「快」或用功能 6、講中文翻外語時，上面那行**原文**偶爾整段是簡體（大約三場遇到一次），譯文不受影響。已經實測 29 次連線，跟 Google 指定原文用繁體、甚至反過來要求簡體，這個模型都不理會——不是設定沒調對，是改不了。② 功能 3 選「準」又選「翻成繁體中文」，但講者講的是中文時（例如混合會議現場的人講中文），原文會是簡體（2026-09-19 實測 1 次）；譯文仍是繁體，只是等於把中文改寫一遍。真的需要那份原文：把 `.txt` 貼到任何簡繁轉換網站轉一次；① 的情況也可以改用功能 3 的「準」模式（準確模式的原文是另一個模型出的，會照指定用繁體；功能 6 沒有「準」模式可換）|
| 插著耳機時選「麥克風」，收到的是哪一支？ | 有些電腦（例如耳機和麥克風共用一個插孔（耳麥二合一）的筆電）插著耳機時，會自動改用**耳機上的麥克風**，拔掉才改回電腦的麥克風（2026-09-19 一台筆電實測）。耳機插著卻沒戴、又選「麥克風」時，收到的是掛在一旁的耳機麥克風——把耳機拔掉，或到「設定 → 系統 → 音效 → 輸入」改回電腦的麥克風。開始時畫面會印出收的是哪一支（「麥克風：…」那一行） |
| 逐字稿裡有一段只寫「（整理後的逐字稿略去了這段）」 | 通常是那位講者整場只說了「嗯」「對」這類附和，整理成正式文字時被略去了。留著這一行，是為了讓你事先填好的講者名字不會整排錯位 |
| 桌面上找不到捷徑 | 有些公司電腦不讓程式寫入桌面，這**不影響使用**。直接去資料夾裡點 `4_開始使用.bat` 就好；想要捷徑就在 `4_開始使用.bat` 上按右鍵→傳送到→桌面(建立捷徑) |
| 貼金鑰時畫面出現一排 `*` | 正常，這是為了不讓金鑰明文留在畫面上。按 Enter 後會顯示「收到：AQ.Ab…xyz9（共 53 字）」這種露出頭尾的確認，再跟 Google 確認金鑰是否有效 |
| 金鑰貼錯、過期，或想換一組 | 選單選 **9「API 金鑰設定」**：可以換一組、檢查目前這組是否有效、或清除電腦裡記住的金鑰（共用電腦、要交還電腦時用） |
| 畫面說「API 金鑰有問題」 | 即時字幕先按 Ctrl+C 結束；回到選單選 **9** 檢查或換一組。轉逐字稿、翻譯沒有成功時，選單會自己問 Google 一次，確定是金鑰壞了就直接問你要不要換 |
| 功能 6 進行中，耳機／喇叭完全沒有翻譯語音 | 先確認畫面開頭那行「🔊 翻譯語音將從「⋯」播出」寫的是不是你現在戴著、或正在聽的那一顆。不是的話，回選單重跑功能 6，在「口譯語音要從哪裡聽」改選對的裝置；是的話，把那顆裝置的音量調大、或在 Windows 右下角喇叭圖示裡確認它沒有被靜音。結束時畫面會說「共送出約 N 秒到「⋯」」——那是**送進裝置**的量，不保證你聽得到，所以這行有數字不代表裝置沒問題 |
| 功能 6 用麥克風時，講完之後字幕一直重複同一句、停不下來 | 口譯語音從喇叭放出來、被麥克風錄回去了，模型就一直重複翻自己的聲音，這段時間也一直在計費。先按 Ctrl+C 結束；戴上耳機，在「口譯語音要從哪裡聽？」選你戴著的那副耳機，再重新開始 |
| 用完功能 6，喇叭沒有聲音 | 正常結束、按 Ctrl+C、按視窗的 X 都會自動改回原本的喇叭。萬一當機或被工作管理員關掉，**回到選單（或下次打開選單）就會自動改回來**；等不及的話，點右下角喇叭圖示自己選回原本的喇叭。會議軟體（Teams／Zoom／Webex）的喇叭如果照說明指定成①，程式改不到，要自己改回來 |
| 功能 6（或功能 3 選「快」）按了 Ctrl+C 還在跑 | 會先顯示「收到 Ctrl+C，正在收尾」，大約 3～5 秒存好檔案才結束。這時按視窗右上角的 X 也能結束，但整理好的 `.md` 不會產生（逐字的 `.txt` 還在），選單也會一起關掉；功能 6 的聲音輸出一樣會自動改回來 |
| 想知道哪裡出問題 | 點兩下 `6_診斷.bat`，它會列出 Python、套件、ffmpeg、金鑰、檔案是否齊全，把整個視窗截圖回報（回報方式見「1_安裝說明（先讀這個）」的「卡住的時候」） |
| 其他問題 | 把完整的錯誤畫面截圖回報（回報方式見「1_安裝說明（先讀這個）」的「卡住的時候」） |

## 不想用了？怎麼移除

點兩下資料夾裡的 **`7_解除安裝.bat`**，會跳出一個視窗，把可以移除的東西逐項列出來，
**你自己勾要移除哪些**。沒打勾的完全不會動。

預設幫你勾好的（都是這個工具專屬的，移除很安全）：

- ✅ **你的 Gemini API 金鑰** —— 這個最重要。金鑰等同帳號密碼，
  電腦要轉手、還給單位、或送修之前一定要移除
- ✅ 暫存的會議錄音（`%TEMP%` 裡整場會議的原始聲音，只有程式被強制關掉時才會留下；沒有殘留就不能勾）
- ✅ 桌面捷徑
- ✅ 只有這個工具在用的 Python 套件（`google-genai`、`sounddevice`、`PyAudioWPatch`；已經沒裝的不會列出來）
- ✅ 口譯功能（功能 6）留下的聲音輸出紀錄（`%LOCALAPPDATA%\TIO-Meeting-Genie`，只記「口譯結束後要把聲音輸出改回哪一顆」；
  上次口譯沒有正常結束的話，會先幫你把聲音輸出改回原本那顆再刪）

預設**不**幫你勾的（因為別的程式很可能也在用，勾了可能把別的東西弄壞）：

- ⬜ `numpy`、`scipy`（很常見的通用套件）
- ⬜ ffmpeg（剪片軟體、下載器也常用）
- ⬜ Python 本身（風險最高）
- ⬜ 這整個程式資料夾

勾這幾項時會再跳一次確認視窗跟你說風險。按「開始移除」之前，
還會把**實際要執行的每一個動作**列成清單讓你看過。

> 🔴 **你做出來的逐字稿、字幕、雙語對照檔完全不會被刪。**
> 桌面上那些 `.md` / `.txt` / `.json` 是你的資料，解除安裝程式碰都不會碰。

**如果 Python 已經先被移掉了**，`7_解除安裝.bat` 會告訴你剩下三件事要手動做：
刪資料夾、刪掉環境變數 `GEMINI_API_KEY`（開始功能表搜尋「環境變數」）、刪桌面捷徑。

### 🔴 安裝時說「憑證錯誤」、套件裝不起來

錯誤訊息裡如果看到 `SSLError`、`certificate`、`Could not fetch URL https://pypi.org/...`，
代表**公司／學校的防火牆或防毒在攔截 HTTPS**，Python 認不得它換上的憑證，
所以連不上套件伺服器。**不是你操作錯誤，也不是程式壞掉。**

安裝精靈會自動改用「Windows 憑證存放區」重試一次（那裡有 IT 裝的根憑證）。
還是不行的話，畫面上會直接給你三個選項：

| 做法 | 說明 |
|---|---|
| ① **換網路再裝一次** ⭐ | 用手機開熱點，跑一次 `3_安裝.bat`。公司網路如果只擋下載套件，裝好之後就能照常使用；使用時若出現「憑證被攔截」，代表連 Google 也被擋，要請 IT 放行 `generativelanguage.googleapis.com` |
| ② 請 IT 開白名單 | `pypi.org` 和 `files.pythonhosted.org` |
| ③ 略過憑證檢查 | 畫面上有按鈕，會先跟你說明取捨並要你確認 |

**建議先試 ①**，最快也最乾淨——套件只要裝一次，之後就不需要再連 PyPI 了。

### 🔴 資料夾刪不掉怎麼辦

有時候 Windows 會說「您必須提供系統管理員權限，才能刪除此資料夾」。
**這幾乎都不是真的權限問題**，而是還有程式抓著裡面的檔案。照這個順序處理：

1. ⭐ **關掉檔案總管裡開著這個資料夾的視窗**（含它的子資料夾），以及所有這個
   工具的黑色視窗，再刪一次
   → 實際發生過的案例就是這一項：資料夾被自己開著，所以刪不掉
2. 還是不行 → **重新開機，開機後第一件事就是刪它**
   （這步同時是診斷：重開機後刪得掉，就代表剛才只是被鎖住，不是權限問題）
3. 還是不行 → 點兩下資料夾裡的 **`8_刪不掉時救援.bat`**

`8_刪不掉時救援.bat` 會先**只檢查不刪東西**，告訴你：擁有者是誰、你有沒有權限、
有哪個程式正在使用它。要不要動手會另外問你一次。它只碰這一個資料夾。

> ⚠ 網路上會教你用 `takeown` / `icacls` 改權限。這個資料夾如果在 OneDrive 裡，
> 那樣做有機會影響到同步的其他檔案，**請不要照做**。
