# 安裝說明

> **資料夾裡的檔案有編號，照號碼順序做就對了。**
>
> | 編號 | 什麼時候用 |
> |---|---|
> | `1_安裝說明` | 就是這一份，先讀 |
> | `2_申請金鑰與儲值` | **第一次一定要做**，約 10 分鐘 |
> | `3_安裝.bat` | 點兩下，自動裝好 |
> | `4_開始使用.bat` | 開啟選單。**平常點桌面的「TIO語音精靈」捷徑就好**（捷徑開的就是它），桌面沒有捷徑時才直接點這個 |
> | `5_使用說明` | 功能怎麼操作，隨時查 |
> | `6_診斷.bat` | 出問題時執行，把畫面截圖回報 |
> | `7_解除安裝.bat` | 不想用了 |
> | `8_刪不掉時救援.bat` | 資料夾刪不掉時才用 |

這是一套**會議錄音轉文字**的工具。你收到的資料夾叫 `TIO語音精靈_LVT`，
裡面的程式沒有寫死路徑，放在 C 槽、D 槽、桌面、隨便哪裡都能跑。

## 你的電腦需要具備

| 項目 | 版本 | 說明 |
|---|---|---|
| **Windows** | 10 / 11 | 目前**只支援 Windows**——「錄電腦播放的聲音」用的是 Windows 專屬技術（WASAPI），Mac 用不了 |
| **Python** | 3.12 以上 | **沒裝也沒關係**——`3_安裝.bat` 偵測到沒有時會自動幫你裝好（安裝 3.13） |
| **網路連線** | — | 要連 Google 的伺服器，離線不能用 |
| **一組 Gemini API 金鑰** | — | 你自己申請一把，做法看 `2_申請金鑰與儲值` |

ffmpeg 和 Python 套件由安裝程式自動處理，你不用自己裝。

## 安裝步驟

1. 把 zip **解壓縮**到電腦上任何位置（不要直接在壓縮檔裡點檔案）
2. **先讀 `2_申請金鑰與儲值（第一次必做）.md`**，把 API 金鑰準備好
   （沒先弄也行，安裝時那一欄可以留空，之後再補）
3. **點兩下 `3_安裝.bat`**
   - **沒裝過 Python 也沒關係**：它會自動幫你裝（裝在你自己的帳號底下，
     不需要系統管理員權限），裝完會自己接著跑，不用你再點一次
   - 接著跳出**安裝視窗**：先列出「會在你電腦上做哪些事」，
     你按下「我同意，開始安裝」才會開始動作，過程中有進度條
   - 金鑰可以直接貼上，也可以留白跳過（第一次真正使用時會再問一次）
4. 裝完桌面會出現「**TIO語音精靈**」捷徑，點兩下就能用
   （桌面沒出現也沒關係，直接點資料夾裡的 `4_開始使用.bat`，一樣的）

整個過程不用打任何指令，全部是點兩下。

## 🔴 Windows 說「不安全」、擋住不給執行時

**不是你的電腦有問題，也不是這個工具有病毒。**

從 Email、Teams 或雲端**下載**下來的壓縮檔，Windows 會偷偷貼一個「這是從網路來的」標記。
解壓縮時這個標記會**跟著蓋到裡面的檔案上**——用 WinRAR 解壓實測，
它只蓋在「**會執行的**」那 6 個：

```
3_安裝.bat   4_開始使用.bat   6_診斷.bat   7_解除安裝.bat   8_刪不掉時救援.bat   scripts\rescue.ps1
```

其中 5 個 `.bat` 剛好就是你唯一會去點兩下的檔案（`rescue.ps1` 不用點，是 `8_刪不掉時救援.bat` 在呼叫它）。所以症狀會是
**「安裝、開始使用、解除安裝統統被擋，但說明文件都開得好好的」**。

### 做法：按一次「執行」就好

1. 點兩下 `3_安裝.bat` → 跳出警告（多半標題是「開啟檔案 - 安全性警告」）
2. 按 **「執行」**
   （如果是藍色的「Windows 已保護您的電腦」，先按「**其他資訊**」再按「**仍要執行**」）
3. 安裝程式一跑起來，**第一件事就是把整個資料夾的這個標記清掉**——
   同意頁上會看到那一條：「解除這個資料夾裡 N 個檔案的『來自網路』封鎖」

**只有第一次那一下會跳**（那時候程式根本還沒開始跑，擋不掉）。按過之後，
`4_開始使用.bat`、`7_解除安裝.bat` 都不會再被問。

### 想連第一次都不跳：先解除封鎖（純滑鼠，10 秒）

**還沒解壓縮**：

1. 對下載下來的壓縮檔（`.zip`）按**右鍵** →「**內容**」
2. 最下面若有一行「安全性：此檔案來自其他電腦…」，把「**解除封鎖**」**打勾**
3. 按「**確定**」
4. **然後才解壓縮**

**已經解壓縮了**：

1. 對資料夾裡的 `3_安裝.bat` 按**右鍵** →「**內容**」→ 一樣把「**解除封鎖**」**打勾**
2. 按「**確定**」
3. 點兩下 `3_安裝.bat`——安裝程式第一步會把其他檔案的標記一起清掉

🔴 已經解壓了才回頭對 **zip** 勾是沒有用的（標記早就蓋進每個檔案了）：
改成對 `3_安裝.bat` 勾，或刪掉資料夾重解一次。

內容頁**沒有**「解除封鎖」可勾，代表那個檔案本來就沒有標記：zip 就直接解壓縮，`3_安裝.bat` 就直接點兩下。

### 如果警告視窗**完全沒有**可以放行的按鈕

先看訊息裡提到的是哪一種：

- **「智慧型應用程式控制」**（Windows 11 的保護功能開成「強制」）：點 `.bat` 直接被擋、
  沒有「仍要執行」可按，但**可以自己解**（2026-09-19 筆電實測）——
  **刪掉已經解壓的資料夾** → 對 zip 按右鍵 →「內容」→ 勾「**解除封鎖**」→「確定」→
  **重新解壓縮**，再點兩下 `3_安裝.bat`。
- **「系統管理員」「群組原則」**：這台電腦被單位的資訊政策管住了，你自己繞不過去。
  **請把那個視窗截圖**，連同 `6_診斷.bat` 的畫面一起回報（回報方式見下面的「卡住的時候」）。

## 拿到新版本要怎麼更新？

**把新的 zip 解壓縮到同一個位置、覆蓋舊的就好**，你的逐字稿與字幕檔都在桌面，
不會被動到。接著**再點一次 `3_安裝.bat`**。

解壓縮只會覆蓋同名檔，**不會刪掉舊版留下來的檔案**。所以如果你裝過比較早的版本，
資料夾裡可能同時出現 `安裝.bat` 和 `3_安裝.bat` 這種新舊並存的情況。
安裝程式偵測到時會把清單列出來、問你要不要順便清掉——**勾著就好**。

> 想更省事：更新前把整個舊資料夾刪掉，再解壓縮新的。效果一樣，而且最乾淨。
> （你的產出檔在桌面，不在這個資料夾裡。）

### 🔴 從舊版更新：資料夾與捷徑改名了

這個工具現在叫 **「TIO語音精靈」**，資料夾與桌面捷徑都跟著改名。
所以解壓縮新版之後，你的電腦上會**新舊兩份並存**：

| | 你手上可能是這些舊名 | 新的 |
|---|---|---|
| 資料夾 | `會議字幕工具`／`TIO-會議字幕工具` | `TIO語音精靈_LVT` |
| 桌面捷徑 | 會議字幕工具／TIO-會議字幕工具 | TIO語音精靈 |

**舊捷徑不用自己刪**：跑新版的 `3_安裝.bat` 時會偵測到並順手清掉。
**舊資料夾可以直接刪掉**，刪之前請確認兩件事：

1. 你的逐字稿、字幕、雙語對照檔都在**桌面**，不在這個資料夾裡 —— 刪資料夾不會動到它們
2. 先跑一次新版的 `3_安裝.bat`，確認新版可以正常開啟

> 想一次清乾淨、連 API 金鑰也移除的話，**先**跑舊資料夾裡的 `7_解除安裝.bat`，
> 再解壓縮新版、跑新版的 `3_安裝.bat` 重新設定金鑰。
> 只是要換名字的話不必這樣做，直接刪舊資料夾就好。

## 🔴 要拿來錄真實會議，請先開通付費層

免費層**不扣款**，但有兩個問題：

1. **資料治理**：免費層的內容會被 Google 拿去改進產品，**人工審閱者可能讀到**，
   官方明文警告不要送機密資訊。校務會議談人事、經費、審查意見，這一條就不能過。
2. **額度已經不公開**：Google 現在不公布免費層的實際額度，只叫你登入
   [aistudio.google.com/rate-limit](https://aistudio.google.com/rate-limit) 自己看，
   而且註明「公告的額度不保證」。**沒人能事先算出免費層夠不夠開完一場會**，
   開到一半額度耗盡是無法預防的。

> **還有一件事要讓與會者知道**：轉逐字稿時，錄音會**上傳到 Google 的伺服器**處理，
> 這是這類 API 的運作方式，沒辦法避免。本工具會在處理完後主動要求刪除，
> 但「錄音會離開你的電腦」這件事本身，請事先讓與會者知情。
> 轉到一半把視窗關掉，程式會先把電腦裡的暫存錄音和雲端上的那份刪掉才結束；
> 電腦當機、斷電來不及刪的，下一次轉檔一開始會自動清掉（雲端那份最晚 48 小時自動到期）。

怎麼開通、要儲值多少，`2_申請金鑰與儲值` 裡有一步一步的做法。

兩個容易踩的：

- 每日額度是**美西午夜**重置（≈ 台灣下午 3～4 點），不是台灣的午夜
- 額度算在**專案**上、不是金鑰上。同一個專案發好幾把金鑰給不同人，
  大家共用一份額度會互相排擠 —— **請用你自己的 Google 帳號建立自己的專案**

**費用算在你自己的 Google 帳號上**，本工具不經手任何金流。

回報。它會列出這台電腦的 Python、套件、ffmpeg、
API 金鑰、桌面路徑、檔案是否齊全，一眼看得出卡在哪，不用來回猜。

**回報方式**：到 GitHub 開一則 Issue，或寄信到 cylab.contact@gmail.com。Issue 的網址：https://github.com/cytwn/tio-voice-genie/issues
Issues 是公開的，任何人都看得到：截圖裡的桌面路徑會帶出你的 Windows 使用者名稱，貼上去之前先遮起來，或改用寄信。

### 常見安裝失敗

| 狀況 | 原因 | 解法 |
|---|---|---|
| 點 `.bat` 就跳「安全性警告」、說不安全 | 壓縮檔是從網路下載的，Windows 幫裡面每個 `.bat` 貼了「來自網路」標記 | 按一次「執行」就好，安裝程式會把整包清乾淨；做法見上面〈Windows 說「不安全」〉那一節 |
| 顯示「Python is not installed」 | 這台電腦沒有 Python | `3_安裝.bat` 會自動裝好並接著跑，等它就好 |
| pip install 失敗、出現 `SSLError` / `certificate` | **公司網路在攔截 HTTPS**，Python 不認得防火牆換上的憑證 | 安裝程式會自動用 Windows 憑證存放區重試；還是不行就**用手機熱點跑一次安裝**（最快），或按畫面上的「略過憑證檢查」 |
| ffmpeg 安裝失敗 | winget 沒裝或版本太舊 | 到 [ffmpeg.org](https://ffmpeg.org) 下載，解壓縮後把 bin 資料夾加進系統 PATH |
| 麥克風／電腦聲音錄不到 | 沒有音訊裝置，或 Windows 隱私設定擋住麥克風 | 設定 → 隱私權與安全性 → 麥克風，確認允許桌面應用程式存取 |
| 開始使用時還是要我貼金鑰 | 安裝時跳過了金鑰，或貼的那組 Google 說不能用（安裝完成頁會寫原因） | 照畫面提示貼一次即可，不用重開機；之後想換，選單選 **9「API 金鑰設定」** |
| 安裝時沒跳出視窗、只有黑色文字畫面 | 這台的 Python 沒有 tkinter（很少見） | 照著黑色視窗裡的問題回答即可。⚠ 文字版**不會建立桌面捷徑**，也**沒有 SSL 自動重試**——請直接用 `4_開始使用.bat` 開啟 |
| 桌面沒出現捷徑 | 有些公司電腦的防毒（受控資料夾存取）或群組原則不讓程式寫入桌面 | **不影響使用**：直接點資料夾裡的 `4_開始使用.bat`。想要捷徑就在它上面按右鍵→傳送到→桌面(建立捷徑) |
| 轉檔時說「找不到 ffmpeg」 | 剛裝好，舊視窗的 PATH 還是舊的 | 關掉視窗，重新點一次 `4_開始使用.bat` |
| 剛裝好就用功能 1／3／6，畫面說「載不起語音處理元件（scipy）」 | Windows 11 的**智慧型應用程式控制**會先擋下剛裝好、還沒有雲端信譽的元件（2026-09-20 一台筆電實測遇到） | **等幾分鐘再試一次**就好，它通常會自己放行。想確認的話點兩下 `6_診斷.bat`，看那幾行是 `BLOCKED` 還是 `OK`；等變回 `OK` 再用。功能 5（重新排版）不連網也不用那些元件，這段期間照樣可以用 |
| 按下 Enter 之後畫面停住好幾十秒，像當掉了 | 沒當掉，是在**載入語音元件**。這些元件很大，久沒用時要從硬碟重新讀進來 | 畫面會逐項顯示進度（`· 語音處理元件（scipy）… ✓ 27.2 秒`），看得到就是正常的。**開會前先暖機可以避免**，見下一節 |

## 🔥 開會前先暖機（強烈建議，可省 30 秒）

**開會前先點兩下 `6_診斷.bat`，看完關掉，再點 `4_開始使用.bat`。**

為什麼有效（2026-09-21 一台筆電實測）：

| 情況 | 按下 Enter 後要等 |
|---|---|
| 很久沒用，直接開 | **30～45 秒** |
| 先跑過 `6_診斷.bat` | **約 3 秒** |

`6_診斷.bat` 會把那些大型語音元件真的載入一次，等於先幫你熱身；之後開功能 1／3／6 就快了。
**順便還能看到智慧型應用程式控制有沒有正在擋**（那幾行會顯示 `BLOCKED` 而不是 `OK`）。

> 這個暖機效果只維持一段時間（實測間隔 8 分鐘內仍有效），所以請在**接近開會時**做，不要前一天做。

## 不想用了？點兩下 `7_解除安裝.bat`

會跳出視窗，把可以移除的東西逐項列出來讓**你自己勾**，沒勾的完全不動。

- 預設勾好：**API 金鑰**、暫存的會議錄音（有殘留時）、桌面捷徑、這個工具專用的 Python 套件、口譯功能（功能 6）留下的聲音輸出紀錄
- 預設不勾（別的程式可能也在用，勾了會再警告一次）：`numpy`／`scipy`、
  ffmpeg、Python 本身、程式資料夾
- 套件那兩項只會列出**這台電腦真的還裝著的**；已經移除過的不會再出現，也勾不到
- 按「開始移除」之前會把**實際要執行的動作**整份列出來讓你確認

🔴 **你做出來的逐字稿與字幕檔一律保留**，解除安裝程式不會去碰它們。

> ⚠️ **電腦要轉手、還給單位或送修之前，請務必跑一次解除安裝把 API 金鑰移掉。**
> 那把金鑰等同你 Google 帳號的帳密，留在電腦裡等於把帳號留給下一個人。

**資料夾刪不掉時**（Windows 說「需要系統管理員權限」）：這幾乎都不是權限問題。
**最常見的原因是那個資料夾正開在檔案總管裡**（已實際發生過）——關掉那個視窗就好。
還是不行就重新開機後再刪；再不行才點兩下 `8_刪不掉時救援.bat`，
它會印出擁有者、權限、以及是哪個程式在佔用，可以直接截圖回報。
