# 申請 Gemini API 金鑰與儲值

> 這一份是**第一次使用前一定要做**的事。建議先做完再執行 `3_安裝.bat`（安裝時金鑰那一欄也可以先留空，第一次使用時會再問）。
> 全程大約 10 分鐘（申請金鑰 2 分鐘，設定付費 5～8 分鐘）。

---

## 這是什麼、為什麼要做

這個工具本身不收費，它是把聲音送給 **Google 的 Gemini** 做辨識。
你需要一把「鑰匙」（API 金鑰）讓 Google 知道是誰在用、費用算給誰。

**金鑰等同你 Google 帳號的密碼**，不要給別人、不要貼在群組裡。

---

## 第一步：申請 API 金鑰（免費，2 分鐘）

1. 用瀏覽器開 **[aistudio.google.com/apikey](https://aistudio.google.com/apikey)**
2. 用你的 Google 帳號登入
3. 第一次進去會要你同意服務條款，勾選後繼續
4. 點 **「Create API key」／「建立 API 金鑰」**
5. 它會產生一串以 `AQ.`（新的金鑰）或 `AIza`（較早的金鑰）開頭的長字串 → **點複製**

複製好之後，執行 `3_安裝.bat`，安裝精靈會問你要不要貼上。

> 💡 沒有先申請也沒關係：安裝精靈那一欄可以留空跳過，
> 第一次真正開始用的時候程式會再問你一次。

### 幾件要知道的事

- **每個人請用自己的 Google 帳號申請自己的金鑰。**
  金鑰的用量和費用算在申請人的帳號上，共用一把等於帳單全記在同一個人頭上。
- 金鑰背後綁著一個 **Google Cloud 專案**。AI Studio 第一次會自動幫你建一個。
- 額度是**算在專案上，不是算在金鑰上**。同一個專案發好幾把金鑰給不同人，
  大家會共用同一份額度、互相排擠。

---

## 第二步：開通付費（重要，請不要跳過）

### 為什麼一定要付費層

免費層**真的不扣款**，但代價寫在 Google 的服務條款裡：

| | 免費層 | 付費層 |
|---|---|---|
| 費用 | 不收費 | 用多少算多少 |
| **你送出的會議錄音會不會被拿去改進 Google 產品** | **會** | 不會 |
| **真人審閱者可能讀到你的會議內容** | **可能** | 不會 |
| 額度 | Google 已不公開實際數字 | 高很多 |

校務會議談的是人事、經費、審查意見、學生個資。
**只要是這類內容，就不該用免費層。**

還有一個實務問題：Google 現在**不公開免費層的實際額度**了
（官方 rate-limits 頁面已移除逐模型的額度表），所以沒有人能事先算出
「免費層夠不夠開完這場會」——包括本工具的開發者。
會議開到一半額度耗盡，是無法預防的。

### 怎麼開通

1. 開 **[aistudio.google.com/apikey](https://aistudio.google.com/apikey)**
2. 找到你金鑰所屬的專案，那一列會顯示 **Free**
3. 點該列的 **「Set up Billing」／「設定帳單」**
4. 依畫面指示建立或選擇一個 **Cloud Billing 帳戶**（要填信用卡）
   - 從來沒設定過 Google 帳單 → 跟著精靈一步步建立即可
   - 以前設定過 → 它會讓你從既有的帳單帳戶裡選一個
5. 新帳戶預設是**預付制（Prepay）**，會要求你**先儲值最低 US$5**
   才能完成設定
6. 完成後回到 AI Studio，那一列會從 **Free** 變成 **Paid**

> 官方原文：
> "Asked to prepay a minimum of $5 to complete billing"
> —— [ai.google.dev/gemini-api/docs/billing](https://ai.google.dev/gemini-api/docs/billing)
> （2026-09-08 查證）

---

## 第三步：了解預付制怎麼運作（避免會議中斷）

新帳戶預設是 **Prepay（預付）**：先儲值，用掉就扣，扣完就停。

### 🔴 最重要的一條

> "When your Prepay credit balance on the billing account hits $0, all API keys in
> all projects linked to that billing account will stop working simultaneously."
> —— 官方 billing 頁面

**餘額歸零的那一刻，掛在同一個帳單帳戶底下的所有金鑰會同時停止運作。**
會議進行到一半發生的話，字幕會直接停掉。

### 怎麼避免

**① 開會前先確認餘額夠**

用這張表換算（2026-09-19 實測核對；各工具用哪個模型見 `5_使用說明` 的「要花多少錢」）：

| 用途 | 一小時大約花費 | 儲值 US$5 約可用 |
|---|---|---|
| 影音檔轉逐字稿 | US$0.62（約 NT$20） | 約 8 小時 |
| 會議即時字幕 | US$0.54（約 NT$17） | 約 9 小時 |
| 即時雙語字幕・準確模式 | US$0.57（約 NT$18） | 約 9 小時 |
| 即時雙語字幕・快速模式 | **US$2.21（約 NT$71）** | **約 2.3 小時** |
| 即時語音翻譯 | **US$2.21（約 NT$71）** | **約 2.3 小時** |
| 逐字稿轉雙語對照（已有逐字稿） | US$0.51（約 NT$16） | 約 10 小時的逐字稿 |

**儲值 US$5（約 NT$160）大約可以用：輸出文字的功能（逐字稿、即時字幕、雙語字幕準確模式、逐字稿轉雙語）約 8～10 小時；
輸出語音的功能（雙語字幕快速模式、即時語音翻譯）只有約 2.3 小時。**
一個月開十場兩小時的會：只用文字功能抓 US$15 上下；如果全程用語音翻譯，要抓 US$45 上下。

**② 開啟自動儲值（Auto-reload）**

在 Google Cloud 的帳單頁面可以設定「餘額低於 X 就自動加值 Y」，
並且設**每月自動扣款上限**，避免異常用量把卡刷爆。
會議前不用再手動檢查餘額，這是最省事的做法。

**③ 設定預算警示**

Google Cloud Console → 帳單 → 預算與快訊，設一個每月預算，
超過門檻會寄信通知你。

> ⚠️ 官方提醒：預付制的扣款有**約 10 分鐘的延遲**，
> 所以餘額可能會短暫超支一點點。長時間的工作要多留一點餘額。

---

## 第四步（選用）：查自己現在的額度

Google 已經不在公開文件裡列出各層的額度數字了，只能登入查自己的：

**[aistudio.google.com/rate-limit](https://aistudio.google.com/rate-limit)**

> 官方註明："Specified rate limits are not guaranteed and actual capacity may vary."
> （公告的額度不保證，實際容量可能不同）

另外一條實務上會踩到的：
**每日額度是在「美西午夜」重置，換算成台灣時間大約是下午 3～4 點**
（依美國日光節約時間而定），不是台灣的午夜。
早上把額度用完，要等到當天下午才恢復。

## 常見問題

| 問題 | 說明 |
|---|---|
| 金鑰長什麼樣子？ | 一串英數字：新的金鑰是 `AQ.` 開頭，較早的是 `AIza` 開頭（39 個字元）。貼進程式時畫面會顯示成一排 `*`，按 Enter 後只露出頭尾幾個字讓你核對 |
| 金鑰不見了可以再看嗎？ | 可以，回 aistudio.google.com/apikey 就看得到 |
| 不小心貼到群組怎麼辦？ | 立刻去 AI Studio 建一把新的、停用舊的，然後打開 TIO 選單選 **9「API 金鑰設定」→ 1**，貼上新的並選「記住」 |
| 我沒有信用卡 | 那就只能用免費層，**請不要拿來錄涉及個資或機密的會議** |
| 會不會被扣一大筆？ | 預付制不會——餘額用完就停。只是扣款有約 10 分鐘延遲，可能短暫超支一點點（見上面的官方提醒）。這也是預設方案 |
| 我已經有 Google Cloud 帳號 | AI Studio 不會自動建專案，要自己匯入既有專案再建金鑰 |
| 公司電腦說沒有權限建立金鑰 | 那個 Google Cloud 專案屬於組織，要請管理者授權；或改用不隸屬組織的個人專案 |
